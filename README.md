# Controle de Serviços de Ar Condicionado

Sistema para cadastrar e acompanhar serviços de instalação, limpeza e manutenção de ar condicionado. O projeto nasceu da minha rotina de trabalho na área e da vontade de aplicar o que estou aprendendo no curso de Análise e Desenvolvimento de Sistemas.

**Site online:** https://viniciusbuilds-code.github.io/controle-servicos-ar-condicionado/

## Versão web (index.html)

- Cadastro, edição e exclusão de serviços
- Painel com faturamento do mês, valores recebidos e a receber
- Gráfico de faturamento dos últimos 6 meses
- Busca por cliente ou telefone e filtros por tipo e status
- Marcar serviço como pago ou pendente
- Exportação para Excel (CSV)
- Layout responsivo, funciona no celular
- Tecnologias: HTML, CSS e JavaScript

Os dados ficam salvos no navegador de quem usa o site.

## Versão em Python (controle_servicos_v2.py)

Programa de terminal com cadastro, busca, edição, exclusão, status de pagamento, relatório mensal e exportação para CSV. Os dados ficam no arquivo servicos.json.

Para rodar:

    py controle_servicos_v2.py
